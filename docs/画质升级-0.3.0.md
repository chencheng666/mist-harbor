# 雾港 0.3.0：程序化画质与战斗反馈

本轮在原项目上独立实现小体积程序化 FPS 的技术方案。参考作品仍为独立部署的《几猫》，未引入其代码、模型、纹理或声音资源。

## 实际完成

- 材质：三组程序化颜色、法线与粗糙度纹理，材质变体缓存、按表面方向的湿度和污渍；移除发行目录中不再使用的扫描图片。
- 渲染：程序化天空与 PMREM 环境，PCSS 式遮挡搜索和接触软阴影；HDR 场景与枪械统一后处理，半分辨率深度 AO、查询阴影的体积光、深度引导模糊、四级泛光、GPU 自动曝光、调色与 FXAA。
- 环境：连续干地、潮湿与积水过渡，镜像相机与斜裁剪平面反射；GPU 实例化雨线、屋顶遮雨、雨圈、多频海浪和可进入的检修棚。棚内增加货架、工作台、电气柜、标识与独立环境反射。
- 枪械：缩窄导轨和机匣；瞄具玻璃通过视线角度生成分划；后坐、转向惯性和落地分别使用弹簧；左手、弹匣与枪机按换弹阶段运动，空仓与战术换弹时长不同；微表面湿度与室内照明平滑切换。
- 守卫：圆角装甲、独立传感器弱点；四足落脚规划和两段腿 IK；巡逻、调查、交战与搜索状态，最后已知位置、声音警觉、同伴警报；A* 八方向绕障和对角防穿角；限制同时攻击的令牌与预警；飞行守卫坠落、地面守卫残骸。
- 特效：固定容量火花、弹壳、烟雾、弹痕和曳光；按表面区分命中，实例化弹壳与火花、烟雾排序、反弹与回收、两盏共享瞬时灯。
- 声音：预生成射击变体、脚步、撞击与装填音；空间声源、室内外卷积混响、雨风环境、随交战强度变化的底音和节奏，声部预算与优先级。
- 输入与物理：地面加减速、瞄准减速、跳跃缓冲和离地宽限、落地反馈、头顶空间检查；保留多触点移动、拖动开火与换弹。
- 性能：静态箱体与标牌实例化、机械守卫零件合批；GPU 定时查询优先的动态分辨率与画质降档，可手动关闭；半分辨率效果、反射和阴影错帧更新；后处理失败可退回基础渲染。

## 验收范围

本地 Ego 浏览器完成：空仓和战术换弹的弹药守恒、暂停恢复、集装箱碰撞、墙体遮挡、连续射击击毁、跳跃、瞄准、三座信标与撤离、失败重试、画质切换、室内混响。四个任务目的地的网格可达性通过。任务流程使用本地显式测试接口进行受控验收，不宣称人工无辅助通关。

重新部署四轮后，观测到的几何资源数保持 181，运行错误为空。此检查验证本轮资源回收，不等于长时压力测试。844 × 390 浏览器触屏模拟与本地 file 协议离线文件另行保存验收记录；不宣称实体手机、Safari 或所有 GPU 已验证。

设备观测帧率与 GPU 时间分别报告：浏览器存在约 30 FPS 的限帧情况，均衡档一个持续运行样本的 GPU 时间约 13.3 ms、CPU 渲染提交约 1.7 ms；不能将 GPU 时间直接换算为已达到的显示帧率。标题场景绘制调用的单帧观测从旧版约 583 到新版约 113；统计包含错帧反射、阴影与后处理，不能视作所有视角的固定提升比例。

## 边界

本轮没有实现参考作品的全部功能。没有宣称光线追踪、完整全局光照、全场景物理破坏、完整骨骼动画系统、屏幕空间运动模糊或专业音频成品。材质图由 CPU 程序生成后上传 GPU，雨和着色效果由 GPU 计算；没有把这两种生成方式混为一谈。平面反射每隔若干帧更新，快速转头可能观察到更新滞后。

历史 0.2 公众号文章中的 52 分钟与 Token 数字不包含本轮升级，不能继续用来描述 0.3 的开发总量。
