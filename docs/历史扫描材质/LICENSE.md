# 扫描材质来源

以下材质来自 Poly Haven，按照 CC0 1.0 提供，可以随游戏重新分发：

- [Asphalt 02](https://polyhaven.com/a/asphalt_02)：沥青颜色、OpenGL 法线、粗糙度。
- [Rusty Painted Metal](https://polyhaven.com/a/rusty_painted_metal)：集装箱颜色、OpenGL 法线、粗糙度。
- [Metal Plate](https://polyhaven.com/a/metal_plate)：枪械和工业金属的法线、粗糙度。

原始文件 URL、文件大小和 SHA256 保存在同目录 `sources.json`。游戏运行使用本地文件，不依赖材质站联网。
