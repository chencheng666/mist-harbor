# 雾港 1.0.0：场景与枪械重建

0.3 的主要问题是连续重复的货箱长廊、偏亮且重复的湿地面、厚板式枪械轮廓，以及部分工业构件没有实际绘制。1.0 重建这些直接影响实机观感的部分。

## 场景与光照

- ISO 比例货箱、错落堆垛、入口装卸广场与交叉口，保留三信标和码头撤离任务。
- 折弯波纹侧板、双扇箱门、锁杆、角件、铰链、货运标识和局部锈蚀水痕。
- 开放桁架吊机、轮组、梯子、检修步道与吊索；近景增加斜面护栏、路锥、灯杆底座和告示牌。
- 检修棚增加梁、檩条、墙根、排水管、混凝土地坪、货架、工具板与电气柜。
- 重建码头岸线与充气撤离艇，海面采用多方向几何波与细波法线，按非金属水面处理反射。
- 湿地使用域扭曲噪声，避免正弦纹理的规律条带；干燥、潮湿、积水连续过渡，并配合车辙、裂缝和细碎杂物。
- 调整风暴天空、低角度暖阳和冷色环境光。阴影视野集中在玩家附近；流畅档保留 1024 基础阴影，均衡与精细档使用更高分辨率和软阴影。

## 武器与战斗

- 按尺寸重新构建 AR–07：锻造机匣、带真实通孔的八面护木、枪管与导气管、薄型导轨、弹匣、抛壳窗、枪机和小型全息瞄具。
- 拆分金属、聚合物、橡胶与布料；表面包含微观粗糙度、边缘磨耗和雨滴。重新塑造手掌、指节、袖口与衣褶。
- 保留多轴弹簧、开火后坐、瞄准、空仓/战术换弹和分阶段装填音；调整持枪与瞄准位置。
- 新增 F / 触屏枪灯，使用真实聚光灯、遮挡与柔和光斑。开启枪灯会增加被守卫发现的距离与速度。
- 武器主光方向随玩家朝向变化，并检查场景遮挡；进入棚内时切换环境反射与音响混响。
- 机械犬补充电机、传动件、散热片、线缆与脚掌结构；无人机补充电机、保护撑杆、电池绑带和传感器。继续使用实际感知、绕障、攻击预警及四足 IK。

## 修正的绘制问题

静态构件先进入实例批次，再进行普通箱体合批。旧逻辑没有排除 `InstancedMesh`，某些材质与阴影设置相同时，会将整个实例批次当成一个普通网格处理，丢失大量几何。

1.0 明确排除已经实例化的网格，并将实例提交移到全部构件生成之后。验收核对生成与保留数量均为 **4,823**，避免只检查程序没有报错。

## 验收与体积

- 21 项玩法检查通过，覆盖枪灯、两类换弹、暂停、碰撞、遮挡射击、击毁守卫、跳跃、蹲伏、瞄准、三座信标、撤离结算、失败重开、画质切换与室内混响。
- 新地图 A / B / C / 撤离四条导航路径均可达。
- 连续四次重新开始，已分配几何资源数量均为 325；这是短期重复重开检查，不代表长时间压力测试。
- 844 × 390 触屏模拟验证多触点移动、转向、射击、换弹和枪灯；实体手机尚未实测。
- 单文件 HTML **853,360 字节（约 0.814 MiB）**；静态目录 **853,568 字节**。没有新增外链纹理、模型或音频资源。
- 正常入口保留只读快照；仅带 `?test=1` 的地址开放可写验收接口。

这是程序化浏览器 FPS 的 1.0 迭代，没有采用扫描角色、光线追踪或完整物理引擎。视觉验收使用运行中的游戏截图；不把后处理技术项数量当作与商业 3A 画质等同的证明。

## 架构

`game.js` 负责输入、移动碰撞、感知/导航、战斗、任务和 UI；`world.js` 生成港区并管理实例、碰撞与交互点；`terrain.js` 处理湿地、反射、海面和雨；`art.js` 生成材质、天空与 HDR 管线；`rifle.js` 是独立相机下的枪械与动画；`weapon.js` 提供机械守卫和合成音效；`effects.js` 管理固定容量的粒子与弹痕。

所有构建仍由浏览器原生 JavaScript 与随包 Three.js 完成。`scripts/package.mjs` 将脚本、样式和许可证内嵌成离线 HTML；腾讯云脚本生成逐文件摘要，备份后原子切换雾港目录，核验其他游戏路由与服务。
